Glowing Badge

New

A status badge with a pulsing glow dot. Six variants, three sizes, and states for hover, focus, active and disabled — built on the Deha pill, card and button primitives.

Variants

Each variant maps to a Deha semantic color. The glow is the badge fill blurred behind it, so color stays in one place.

States & transitions

Rest breathes the glow on a 3.2s loop. Hover lifts 1.5px and blooms the glow to full; the fill color does not change. Active presses to 0.97. Focus draws an emerald ring. Disabled drops the glow entirely.

rest Live Glow breathes 0.85 → 1.0 opacity.
hover / active 220ms ease-out lift, blur 7 → 10px.
focus-visible 2px emerald ring, 3px offset.
static (pulse off) Pending No ring, fixed glow — for dense tables.
no dot Offline Label-only, glow retained.
disabled Live 40% opacity, desaturated, inert.

On buttons

Inside a filled button use the neutral variant — a second glow on emerald competes with the button's own. Anchored to a corner it works as a notification marker.

3

In lists and tables

One badge per row, right-aligned in a fixed column. Only the row that is genuinely active pulses; everything else uses the static form so the list stays calm.

In navigation

As a system-status marker in an app bar, and as a "new" flag on sidebar items. At this size the label goes to 9.5px and the pulse stays on — it is the only motion in the chrome.
