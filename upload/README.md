# Upload batches for the Claude Design design system

One folder per Claude Design upload choice. Upload every file in a folder in one batch, paste that folder's README prompt.
Order: 4-replace, 2-update, 3-append, 1-add.

- `upload/1-add/` Add a completely new component: 22 files
- `upload/2-update/` Update an existing component page: 30 files
- `upload/3-append/` Append to an existing component page: 18 files
- `upload/4-replace/` Replace the entire component: 7 files
- `upload/_duplicates/` skipped: 21 files
